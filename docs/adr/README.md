# Architecture Decision Records

ADRs preserve the context and tradeoffs behind consequential, difficult-to-reverse
decisions.

Use a four-digit sequence and a short title, for example
`0003-domain-driven-design.md`. Start from [the ADR template](template.md). Each record
should contain status, context, decision, consequences, alternatives, and date. Accepted
ADRs are superseded by a new ADR rather than silently rewritten.
